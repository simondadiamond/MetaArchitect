# Brain v2 — Topic Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the second brain's 138 flat one-fact notes into ~25 ever-growing topic pages with section-level retrieval and a real retirement operation, so `brain find` can never return a superseded decision as authoritative.

**Architecture:** The storage unit changes from the file to the `##` section. A new `tools/lib/section.mjs` parses a page body into sections (heading, state line, live body, history block); `index-file.mjs` emits one INDEX row per *live* section instead of one per file; `find` returns `page.md#anchor`. Retirement moves a section's prior body into a collapsed `<details>` history block carrying `status: superseded` and a `by:` anchor — history stays on disk and in git but is never an INDEX row, so ranking cannot surface it. Notes move into Johnny.Decimal *area* folders (blocks of ten, no decimal IDs) behind a single `resolveNote(slug)` so nothing outside `paths.mjs` knows about folders.

**Tech Stack:** Node 20+ ESM (`.mjs`), zero runtime dependencies, `node:test` + `node:assert/strict`, git for atomicity, Supabase for the embedding channel only.

**Spec:** `docs/superpowers/specs/2026-08-06-brain-topic-pages-design.md` (MetaArchitect repo). Read it before Task 1.

**Working directory:** `~/projects/brain`. This is its own git repo. All paths below are relative to it unless prefixed.

## Global Constraints

- **CLI signatures are frozen.** `brain find <q>`, `brain save <fact> --domain <d>`, `brain source find|add`, `brain promote|drop|doctor|sync|inbox|describe|import` must keep working with their existing arguments. The `research`, `teardown-research`, `blog-factcheck`, and `write-post` skills call `source find` / `source add` directly and are not being updated. New flags may be added; existing ones may not change meaning.
- **`notes/` is the source of truth. `INDEX.md` is always derived** and is regenerated by `doctor --fix` / `scan()`. Never hand-write an INDEX line outside `formatIndexLine`.
- **Domain values are unchanged:** `business`, `content`, `infra`, `personal`, `family`, `health`, `finance` (exported as `DOMAINS` from `tools/cmd/save.mjs`). Folder location and `domain` frontmatter are independent — four domains share the `40-49-life` area.
- **Statuses:** `confirmed`, `evidence` (page/section level, exported as `STATUSES`), plus `superseded` which exists **only** on history entries and never as a page-level frontmatter status.
- **Every write stays atomic.** `saveNote()`'s validate → slug → attach → write-note → write-index → commit staging with full rollback on any post-first-write failure must survive every change. Never introduce a path that can leave the tree half-written.
- **The one invariant:** retired content emits no default INDEX row and is not embedded. It is reachable only via `brain find --history`, which labels every result retired.
- **Test command:** `npm test` (= `node --test tools/tests/*.test.mjs`). All existing tests must stay green at every commit.
- **Name collision to avoid:** `tools/cmd/save.mjs` already defines a local `firstSentence()` capped at 140 chars for note descriptions. `tools/lib/section.mjs` exports a different `firstSentence()` capped at 200 for INDEX rows. **Do not import one over the other.** If `save.mjs` needs the section variant, import it as `import { firstSentence as sectionSentence } from '../lib/section.mjs'`.
- **Commit after every task.** Never use `--no-verify`. Never force-push.

import { existsSync, readdirSync } from 'node:fs';
import { dirname, join, relative } from 'node:path';
import { fileURLToPath } from 'node:url';
const REPO_ROOT = join(dirname(fileURLToPath(import.meta.url)), '..', '..');
export const ROOT = process.env.BRAIN_ROOT ?? REPO_ROOT;
export const NOTES_DIR = join(ROOT, 'notes');
export const ASSETS_DIR = join(ROOT, 'assets');
export const INBOX_DIR = join(ROOT, 'inbox');
export const DAILY_DIR = join(ROOT, 'daily');
export const INDEX_PATH = join(ROOT, 'INDEX.md');
export const LOG_PATH = join(ROOT, '.log', 'brain.jsonl');

// Johnny.Decimal AREAS only — blocks of ten, no per-note decimal IDs. Four
// domains share 40-49-life: the folder is location, `domain` frontmatter stays
// the semantic tag, so every --domain filter and the Supabase projection are
// unaffected by the move. 50-59, 60-69 and 70-79 are deliberately free.
export const AREAS = {
  business: '10-19-business',
  content: '20-29-content',
  infra: '30-39-infra',
  personal: '40-49-life',
  family: '40-49-life',
  health: '40-49-life',
  finance: '40-49-life',
};
export const SOURCES_AREA = '80-89-sources';
export const SYSTEM_AREA = '90-99-system';
export const RECIPES_DIR = join(NOTES_DIR, SYSTEM_AREA, 'recipes');
const ALL_AREAS = [...new Set(Object.values(AREAS)), SOURCES_AREA, SYSTEM_AREA];

export function areaFor(domain) {
  return AREAS[domain] ?? SYSTEM_AREA;
}

export function notePath(slug, domain) {
  return join(NOTES_DIR, areaFor(domain), `${slug}.md`);
}

// Slugs are globally unique across areas (doctor enforces it), so a linear
// scan is correct and cheap at this scale. Returns null rather than throwing —
// callers distinguish "no such page" from "unreadable page".
export function resolveNote(slug) {
  for (const area of ALL_AREAS) {
    const p = join(NOTES_DIR, area, `${slug}.md`);
    if (existsSync(p)) return p;
  }
  return null;
}

export function relNotePath(absPath) {
  return relative(ROOT, absPath).split(/[\\/]/).join('/');
}

export function allNoteFiles() {
  const out = [];
  for (const area of ALL_AREAS) {
    const dir = join(NOTES_DIR, area);
    if (!existsSync(dir)) continue;
    for (const f of readdirSync(dir)) {
      if (f.endsWith('.md') && !f.startsWith('.')) out.push(join(dir, f));
    }
  }
  return out.sort();
}

Create `tools/lib/section.mjs`:

```js
// tools/lib/section.mjs — a page body is an ordered list of ## sections.
// Each section: heading, optional one-line state, a live body, and an optional
// collapsed history block holding retired bodies. History is deliberately a
// separate field so every consumer must opt in to it: the INDEX, the embedder
// and `find` all read `.body`, which structurally cannot contain retired text.
import { slugify } from './note.mjs';

const STATE_RE = /^`([^`]+)`\s*$/;
const HISTORY_OPEN = '<details><summary>History</summary>';
const HISTORY_CLOSE = '</details>';
const HIST_RE = /^-\s+\*\*(\d{4}-\d{2}-\d{2})\*\*\s*(?:`by:\s*([^`]+)`\s*)?—\s*(.*)$/;

function parseState(line) {
  const m = line.match(STATE_RE);
  if (!m) return null;
  const state = {};
  for (const part of m[1].split('·')) {
    const i = part.indexOf(':');
    if (i < 0) continue;
    state[part.slice(0, i).trim()] = part.slice(i + 1).trim();
  }
  return Object.keys(state).length ? state : null;
}

function serializeState(state) {
  const parts = [];
  if (state.updated) parts.push(`updated: ${state.updated}`);
  if (state.status) parts.push(`status: ${state.status}`);
  return parts.length ? '`' + parts.join(' · ') + '`' : null;
}

export function anchorFor(heading, taken = new Set()) {
  const base = slugify(heading) || 'section';
  let a = base;
  for (let n = 2; taken.has(a); n++) a = `${base}-${n}`;
  return a;
}

export function parseSections(body) {
  const lines = String(body ?? '').split('\n');
  const sections = [];
  const taken = new Set();
  let cur = null;
  let inHistory = false;

  const push = () => {
    if (!cur) return;
    cur.body = cur.bodyLines.join('\n').trim();
    delete cur.bodyLines;
    delete cur.histLines;
    sections.push(cur);
  };

  for (const line of lines) {
    const h = line.match(/^##\s+(.+?)\s*$/);
    if (h) {
      push();
      const heading = h[1];
      const anchor = anchorFor(heading, taken);
      taken.add(anchor);
      cur = { heading, anchor, state: {}, body: '', history: [], bodyLines: [], histLines: [] };
      inHistory = false;
      continue;
    }
    if (!cur) continue;
    if (line.trim() === HISTORY_OPEN) { inHistory = true; continue; }
    if (line.trim() === HISTORY_CLOSE) { inHistory = false; continue; }
    if (inHistory) {
      const m = line.trim().match(HIST_RE);
      if (m) cur.history.push({ date: m[1], by: m[2]?.trim(), text: m[3].trim() });
      continue;
    }
    // The state line is only a state line when it is the first non-empty line
    // of the section — an inline `code` span later in the body is body text.
    if (!cur.bodyLines.length && !Object.keys(cur.state).length) {
      const st = parseState(line.trim());
      if (st) { cur.state = st; continue; }
      if (!line.trim()) continue;
    }
    cur.bodyLines.push(line);
  }
  push();
  return sections;
}

export function serializeSections(sections) {
  const out = [];
  for (const s of sections) {
    out.push(`## ${s.heading}`);
    const st = serializeState(s.state ?? {});
    if (st) out.push(st);
    out.push('');
    if (s.body) { out.push(s.body.trim()); out.push(''); }
    if (s.history?.length) {
      out.push(HISTORY_OPEN);
      out.push('');
      for (const h of s.history) {
        const by = h.by ? '`by: ' + h.by + '` ' : '';
        out.push(`- **${h.date}** ${by}— ${h.text}`);
      }
      out.push('');
      out.push(HISTORY_CLOSE);
      out.push('');
    }
  }
  return out.join('\n').replace(/\n{3,}/g, '\n\n').trimEnd() + '\n';
}

// Pure. Newest retirement goes to the front so the fold reads reverse-chrono.
// The retired text is the section's own prior live body, flattened to one line
// so a history entry is always a single list item.
export function retire(section, newBody, date, byAnchor) {
  const retired = {
    date,
    by: byAnchor,
    text: section.body.replace(/\s+/g, ' ').trim(),
  };
  return {
    ...section,
    body: String(newBody).trim(),
    state: { ...section.state, updated: date },
    history: [retired, ...(section.history ?? [])],
  };
}

export function firstSentence(body) {
  const flat = String(body ?? '').replace(/\s+/g, ' ').trim();
  const m = flat.match(/^.*?[.!?](?=\s|$)/);
  const text = (m ? m[0] : flat).trim();
  if (text.length <= 200) return text;
  const cut = text.slice(0, 201);
  const at = cut.lastIndexOf(' ');
  return (at > 0 ? cut.slice(0, at) : cut.slice(0, 200)).replace(/[,;:\-–—]$/, '').trim();
}
```

```js
import { parseSections, firstSentence } from './section.mjs';
import { relNotePath } from './paths.mjs';

// Path may be nested (notes/<area>/<slug>.md) and may carry a #anchor. The
// marker slot is unchanged — `evidence` and `source` only. `superseded` is
// deliberately absent: retired content never reaches the INDEX at all, so
// there is nothing for ranking to have to outrank.
const LINE_RE = /^- \[([a-z0-9-]+)(?:#([a-z0-9-]+))?\]\((notes\/[a-z0-9-]+\/[a-z0-9-]+\.md(?:#[a-z0-9-]+)?)\) \(([a-z]+)(?:, (evidence|source))?\) — (.+)$/;

export function parseIndex(text) {
  const entries = [];
  for (const line of text.split('\n')) {
    const m = line.match(LINE_RE);
    if (!m) continue;
    const entry = { slug: m[1], path: m[3], domain: m[4], description: m[6] };
    if (m[2]) entry.anchor = m[2];
    if (m[5] === 'evidence') entry.status = 'evidence';
    if (m[5] === 'source') entry.type = 'source';
    entries.push(entry);
  }
  return entries;
}

export function formatIndexLine({ slug, anchor, path, domain, status, type, description }) {
  const marker = type === 'source' ? ', source' : status === 'evidence' ? ', evidence' : '';
  const label = anchor ? `${slug}#${anchor}` : slug;
  return `- [${label}](${path}) (${domain}${marker}) — ${description}`;
}

// One entry per LIVE section. A page with no ## sections (source notes, very
// short pages) yields a single page-level entry so nothing falls out of the
// index during migration.
export function noteToIndexEntries(fm, body, absPath) {
  const rel = relNotePath(absPath);
  const base = { slug: fm.slug, domain: fm.domain };
  if (fm.type === 'source') base.type = 'source';
  else if (fm.status === 'evidence') base.status = 'evidence';

  const sections = parseSections(body).filter((s) => s.body);
  if (!sections.length) {
    return [{ ...base, path: rel, description: fm.description }];
  }
  return sections.map((s) => ({
    ...base,
    anchor: s.anchor,
    path: `${rel}#${s.anchor}`,
    description: firstSentence(s.body),
    ...(s.state?.status === 'evidence' ? { status: 'evidence' } : {}),
  }));
}
```

```js
// tools/cmd/log.mjs — the chronological record. Deliberately NOT a note:
// daily files live outside notes/ so allNoteFiles() never sees them and they
// can never compete with knowledge in `find`.
import { existsSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';
import { DAILY_DIR } from '../lib/paths.mjs';
import { createState, logStage, fail } from '../lib/state.mjs';

const TEMPLATE = (date) => `# ${date}\n\n## Done\n\n## In progress\n\n## Decisions\n\n## Notes touched\n`;
const SECTIONS = ['Done', 'In progress', 'Decisions', 'Notes touched'];

export async function run(argv) {
  const state = createState('log');
  const flagAt = argv.findIndex((a) => a === '--section');
  const section = flagAt >= 0 ? argv[flagAt + 1] : 'Done';
  if (!SECTIONS.includes(section)) fail(state, 'validate', `--section must be one of: ${SECTIONS.join(', ')}`);
  const text = argv.filter((a, i) => !a.startsWith('--') && i !== flagAt + 1).join(' ').trim();
  if (!text) fail(state, 'validate', 'nothing to log');

  const now = new Date();
  const date = now.toISOString().slice(0, 10);
  const time = now.toTimeString().slice(0, 5);
  mkdirSync(DAILY_DIR, { recursive: true });
  const path = join(DAILY_DIR, `${date}.md`);
  if (!existsSync(path)) writeFileSync(path, TEMPLATE(date));

  const lines = readFileSync(path, 'utf8').split('\n');
  const at = lines.findIndex((l) => l.trim() === `## ${section}`);
  if (at < 0) fail(state, 'append', `section '${section}' missing from ${date}.md`);
  let insert = at + 1;
  while (insert < lines.length && !lines[insert].startsWith('## ')) insert++;
  while (insert > at + 1 && !lines[insert - 1].trim()) insert--;
  lines.splice(insert, 0, `- ${time} — ${text}`);
  writeFileSync(path, lines.join('\n'));
  logStage(state, 'done', { path, section });
  console.log(`logged to daily/${date}.md`);
}
```

Register it in `tools/brain.mjs` alongside the other commands.
